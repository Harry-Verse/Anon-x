# Anonymus Room



> A minimalist real-time anonymous chat platform built for private, room-based conversations.



DARK ROOM allows users to instantly connect using a shared room code and communicate in real time without traditional account registration.



# Features



\- Real-time messaging with Socket.IO

\- Anonymous room-based conversations

\- Optional usernames

\- Random private room generation

\- Automatic join and disconnect notifications

\- Responsive mobile and desktop interface

\- Clean modern dark-themed UI

\- XSS-safe message rendering using `textContent`

\- WebSocket-powered communication

\- Lightweight Flask backend



# How It Works



1\. Enter an optional username.

2\. Create or enter a room code.

3\. Share the room code with another user.

4\. Connect and start chatting instantly.



Anyone using the same room code can join the conversation.
